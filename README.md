# Формы отчетности МТСЗН РК

Веб-приложение для заполнения форм отчетности Министерства труда и социальной защиты населения Республики Казахстан.

## 📋 Возможности

- ✅ Онлайн-заполнение 4 форм отчетности
- ✅ Автосохранение данных в браузере
- ✅ Генерация и скачивание DOCX файлов
- ✅ Отправка заполненных документов на сервер
- ✅ Админ-панель для управления документами

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd server
npm install
```

### 2. Запуск сервера

```bash
npm start
```

### 3. Открытие в браузере

- **Форма для заполнения:** http://localhost:3000
- **Админ-панель:** http://localhost:3000/admin

## 🔐 Доступ к админ-панели

- **Логин:** `admin`
- **Пароль:** `admin123`

> ⚠️ **Важно:** Измените пароль перед деплоем на продакшен!

Можно задать через переменные окружения:
```bash
set ADMIN_USER=mylogin
set ADMIN_PASS=mypassword
npm start
```

## 📄 Формы

1. **Форма №1** — Отчет о движении гражданских дел
2. **Форма №2** — Отчет о движении административных дел
3. **Форма №3** — Отчет о движении запросов на согласование
4. **Форма №4** — Отчет об актах судебных и контролирующих органов

## 🛠 API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/documents/upload` | Загрузка документа |
| GET | `/api/documents` | Список всех документов |
| GET | `/api/documents/:id/download` | Скачивание документа |
| DELETE | `/api/documents/:id` | Удаление документа |
| GET | `/api/stats` | Статистика |

## 🌐 Деплой

### На VPS/Сервер

1. Скопируйте файлы на сервер
2. Установите Node.js (v16+)
3. Установите зависимости: `npm install`
4. Запустите через PM2: `pm2 start server.js`

### Настройка Nginx (опционально)

```nginx
server {
    listen 80;
    server_name forms.example.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
    }
}
```
