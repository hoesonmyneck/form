## 🐛 Если что-то не работает

### Проблема: Docker не запускается

**Решение:** Убедитесь, что Docker Desktop запущен.

### Проблема: Порт 3000 занят

**Решение:** Измените порт в `docker-compose.yml`:
```yaml
ports:
  - "8080:3000"  # Теперь приложение будет на http://localhost:8080
```

### Проблема: Ошибка подключения к БД

**Решение:** Перезапустите контейнеры:
```bash
docker-compose down
docker-compose up -d
```

### Проблема: Не могу войти

**Решение:**
1. Очистите localStorage в браузере (F12 → Application → Local Storage → Clear)
2. Попробуйте заново зарегистрироваться

## 🚀 Деплой на сервер

Когда будете готовы к деплою на Linux сервер:

1. Установите Docker на сервере
2. Скопируйте проект на сервер
3. Создайте `.env` с production настройками
4. Запустите `docker-compose up -d`
5. Настройте Nginx + SSL (инструкция в README.md)
