# Инструкция по тестированию новой системы

## Запуск сервера

```bash
npm run test
```

## Тестирование

### 1. Авторизация
- Откройте http://localhost:3000/login.html
- Войдите как **admin** (логин: `admin`, пароль: `admin`)

### 2. Проверка форм
- После входа автоматически откроется страница с формами
- Заполните любую форму (хотя бы частично)
- Нажмите кнопку **"Сохранить"**
- **Перезагрузите страницу** (F5 или Ctrl+R)
- **Проверьте**: данные должны восстановиться

### 3. Проверка админки
- Нажмите кнопку **"Админка"** в правом верхнем углу
- Переключайтесь между вкладками **Форма №1, №2, №3, №4**
- Вы должны увидеть сохраненные данные в виде карточек с:
  - Именем пользователя
  - Организацией
  - Заголовком формы
  - Таблицами с данными

### 4. Фильтры
- Используйте дропдауны **"Все пользователи"** и **"Все организации"**
- Данные должны фильтроваться корректно

### 5. Управление пользователями
- В админке раскройте секцию **"👥 Управление пользователями"**
- Создайте нового пользователя
- Выйдите и войдите под новым пользователем
- Проверьте автозаполнение полей организации

## Что изменилось

1. **Формы теперь сохраняются как JSON**, а не как DOCX
2. **Поддержка кумулятивного заполнения**: можно заполнить частично, сохранить, потом дозаполнить
3. **Админка полностью переработана**: 4 вкладки, каждая показывает данные своей формы
4. **Карточный вид**: каждый пользователь показан отдельной карточкой со всеми заполненными данными

## Известные ограничения

- DOCX файлы пока не генерируются (будет добавлено позже как кнопка "Экспорт в DOCX")
- Старые DOCX файлы не будут отображаться в новой админке
