## Запуск проекта

### Шаг 1: Активация новой версии

```powershell
# В PowerShell (в папке проекта)
Rename-Item -Path "server\server.js" -NewName "server-old.js"
Rename-Item -Path "server\server-new.js" -NewName "server.js"
Rename-Item -Path "admin.html" -NewName "admin-old.html"
Rename-Item -Path "admin-new.html" -NewName "admin.html"
```

### Шаг 2: Установка зависимостей

```bash
npm install
```

### Шаг 3: Настройка окружения

```bash
Copy-Item .env.example .env
```

### Шаг 4: Запуск Docker

```bash
docker-compose up -d
```

### Шаг 5: Проверка

Откройте: **http://localhost:3000**
